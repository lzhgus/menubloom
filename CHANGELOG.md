# Changelog

## 0.5.2

- **Updates, built in.** Menubloom checks for a new version once a day and shows what changed before installing it. Check yourself from the menu bar icon (Check for Updates…) or in Settings ▸ General, where you can also turn automatic checks off.

## 0.5.1

- **The menu shows up right away.** Menubloom's items in the right-click menu no longer lag behind Finder's own, also after your Mac has been idle for a while.
- **The items come back on their own.** If macOS stops Menubloom's Finder extension, the app starts it again within seconds, so you don't need to restart Finder.
- **Settings open about twice as fast** when you start the app.

## 0.5.0

- The first release of Menubloom: New File from templates, Copy Path and Copy As, Open In, Cut & Paste, Copy To and Move To, file actions, image conversion, hidden files and your own shell actions, in Finder's right-click menu.
