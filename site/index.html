Why

Coming from Windows? So did we.

On Windows you right-click in a folder to make a new text file, copy a file's path, or open a terminal right there. Finder's right-click can't do any of it. We ran into this every day, and it's the first thing people new to the Mac ask about. So we put those things back.

Turn on one switch and they're in every Finder window. There are no folders to authorize.

What it adds

Everything you reach for, one right-click away.

New File

Text, Markdown, Word, Excel, HTML, JSON, CSV, Python or Shell, named Untitled and selected. Drop any file into the Templates folder and it becomes a new kind.

Copy Path, Copy As

The full path in one click. Or the name, a ~ path, a shell-quoted path, a file:// URL, a Markdown link, a file's contents, a folder's tree, or a file's MD5, SHA-1 or SHA-256.

Open In

Terminal, iTerm, Ghostty, Warp, VS Code, Cursor and Zed, found on your Mac, plus any app you add. On a file, a terminal opens its folder.

Cut, then Paste

Moves files the way Windows does. A name that's taken gets a number, and it works across disks.

Copy To, Move To

Send the selection to your favorite folders in one step, or pick Other Folder…

Images

Convert to PNG, JPEG, HEIC, TIFF, or an ICNS with every size from 16 to 1024. Or a copy 2048, 1024, 512 or 256 px on its longer side.

File Actions

Make a real Finder alias or a symlink, make a script executable, remove quarantine, dissolve a folder, or delete right away.

Your own actions

Any shell command, with the selection as "$@". Show it only for the file types and folders you pick, and give it a global shortcut.

See it

Twenty seconds in Finder.

The rest of it

Small, quiet, and yours.

Info at a glance

Size, created and modified dates, and an image's dimensions, right in the menu. Click one to copy it.

Arranged your way

Turn any group off, move it up or down, or show its items inline instead of in a submenu.

iCloud Drive too

Finder hides extension menus in cloud folders, so the most-used items are also in right-click ▸ Services.

Nine themes

Settings in light or dark, in nine soft color themes. In English and 简体中文.

Private

No network connections, nothing collected. Your settings stay in ~/Library/Application Support.

Safe by design

Paths reach your commands as arguments, never pasted in, so a file named $(rm -rf ~) is just a name.

Native and light

A menu bar app and a Finder extension. Universal for Apple Silicon and Intel, signed and notarized.

Scripts and Shortcuts

Every item also runs from the command line, so from Shortcuts, Raycast or Alfred.

Free and open source

MIT licensed. Every line is on GitHub.

alias menubloom="/Applications/Menubloom.app/Contents/MacOS/Menubloom" menubloom run copy:path ~/Desktop/a.txt # Copy Path menubloom run new:.md ~/notes # a new Markdown file in ~/notes menubloom run img:png photo.heic # Convert Image ▸ PNG menubloom run open:terminal . # this folder in your terminal

Right-click. That's it.
