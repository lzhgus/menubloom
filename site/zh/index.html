初衷

从 Windows 转过来的？我们也是。

在 Windows 上，在文件夹里点一下右键，就能新建一个文本文件、拷贝文件路径，或者直接在这里打开终端。访达的右键菜单一样都做不到。这是我们每天都会碰到的麻烦，也是刚换到 Mac 的人最常问的问题。所以我们把这些功能补了回来。

打开一个开关，所有访达窗口里就都有了，不用逐个授权文件夹。

新增功能

常用的操作，右键就到。

新建文件

文本、Markdown、Word、Excel、HTML、JSON、CSV、Python、Shell，新建后自动命名为 Untitled 并选中。把任何文件放进模板文件夹，它就成了一种新的文件类型。

拷贝路径、拷贝为

一下拷贝完整路径。也可以拷贝名称、~ 路径、带引号的路径、file:// URL、Markdown 链接、文件内容、文件夹目录树，或者文件的 MD5、SHA-1、SHA-256。

打开方式

终端、iTerm、Ghostty、Warp、VS Code、Cursor、Zed，自动识别你装了哪些，也能自己添加。对文件选终端时，会打开它所在的文件夹。

剪切，再粘贴

像 Windows 一样移动文件。重名时自动加编号，跨磁盘也能用。

拷贝到、移动到

一步把选中的项目送到常用文件夹，或者选“其他文件夹…”。

图片

转换成 PNG、JPEG、HEIC、TIFF，或者包含 16 到 1024 全部尺寸的 ICNS。也能生成长边为 2048、1024、512 或 256 像素的副本。

文件操作

制作真正的访达替身或符号链接，让脚本可执行，移除隔离属性，解散文件夹，或者直接删除。

自定义动作

任意 Shell 命令，选中的路径作为 "$@" 传进去。可以只在你指定的文件类型和文件夹里显示，还能设一个全局快捷键。

还有这些

小巧、安静，按你的习惯来。

简介一眼看到

大小、创建和修改日期、图片尺寸，直接显示在菜单里，点一下就能拷贝。

按你的习惯排

任何一组都能关掉、上移下移，或者不放子菜单，直接平铺在右键菜单里。

iCloud 云盘也能用

访达在云端文件夹里不显示扩展菜单，所以最常用的几项也放进了“右键 ▸ 服务”。

九套主题

设置界面有浅色和深色，九套柔和的配色。支持简体中文和英文。

隐私

不联网，不收集任何数据。设置只保存在 ~/Library/Application Support。

安全

路径以参数传给你的命令，从不拼进命令里，所以名为 $(rm -rf ~) 的文件也只是个名字。

原生、轻量

一个菜单栏 App 加一个访达扩展。通用版本，支持 Apple 芯片和 Intel，已签名并通过公证。

脚本和快捷指令

每一项都能在命令行里运行，所以也能用在快捷指令、Raycast 或 Alfred 里。

免费开源

MIT 许可证，每一行代码都在 GitHub 上。

alias menubloom="/Applications/Menubloom.app/Contents/MacOS/Menubloom" menubloom run copy:path ~/Desktop/a.txt # 拷贝路径 menubloom run new:.md ~/notes # 在 ~/notes 新建 Markdown 文件 menubloom run img:png photo.heic # 转换图片 ▸ PNG menubloom run open:terminal . # 在终端中打开这个文件夹

右键，就这么简单。

免费，支持 macOS 12 及以上，Apple 芯片和 Intel 都能用。
